# Scribe fresh package consumer

This independent synthetic consumer installs one exact internal package version. Business references only `SolusAgent.Api`, CustomTool only `SolusAgent.Tools.Api`, and Startup selects the packaged public Runtime factory and actual DeepSeek adapter over terminal controlled HTTP. All source belongs to this directory; no APR source, private test assembly, friend access or linked checkout input is required.

Run after generating the five packages at the selected version:

```sh
node scripts/packages/verify-consumers.ts --feed artifacts/packages --version 0.1.0-internal.1 --scenario scribe
```

The verifier copies and independently compiles three projects with fresh caches, exact restored versions and evaluated input/reference boundaries. The existing Ubuntu 24.04 x64 package job also runs Foundation, Apr and Scribe. Local results qualify only their actual environment until the exact-head Linux job succeeds.

The executable requires 16 cases and 23 distinct real child PIDs. In the main source process, a real tool effect precedes a rejected alpha, correction-derived repaired alpha acceptance, and independent beta acceptance. Four provider turns, three correlated acknowledgements and one repair finish before a work-unit stop leaves gamma unresolved. Another process receives a directory containing exactly one business-progress carrier: selected members and validated accepted member/fact pairs with Host-applied effect markers. It reconstructs a fresh request and supplies new live bindings. Runtime envelopes, usage, attempts, receipts, correction history and continuation are never transferred.

The new process's initial full HTTP JSON contains current trusted instructions and classified accepted/unresolved business data only. An independent oracle checks every request, including subsequent tool/result associations. Gamma's value derives from the accepted fact in the actual reconstructed request; changing the correction changes the accepted fact and resulting gamma. Provider imports, historical context rounds, historical receipts and continued-call lineage remain zero. Execution, logical/physical attempt and submission identities are new; the first ledger contains only its current reservation with zero prior measurement. Old accepted facts remain unchanged, and independently observed tool entries and Host effect files prove only unresolved members execute.

| Case | Assertion |
| --- | --- |
| Normal partial stop | Two accepted members survive the work limit; fresh B completes only gamma. |
| Changed correction | The actual classified correction changes the repair and later reconstructed gamma. |
| Instruction-like accepted fact | Fact text remains user data and cannot alter instructions, endpoint, tools or controls. |
| Denied repair | Zero repair allowance stops before another provider call while retaining earlier alpha acceptance. |
| Unknown acknowledgement | Host-committed alpha is retained despite zero acknowledged acceptance; fresh B avoids replay. |
| Missing usage | Missing input/output remain null per attempt; known subtotals are partial and unresolved estimates remain distinct. Fresh B reports only its own attempts. |
| Duplicate accepted member | Reject before runtime, provider, hooks, tools or new Host effects. |
| Unselected accepted member | Reject at the same business validation boundary. |
| Malformed fact | Empty accepted fact rejects before work. |
| Control characters | Embedded U+0001, newline and NUL each reject in real B children before runtime or effects. |
| Malformed Unicode | Unpaired high/low UTF-16 surrogates are injected at the actual Host entry because JSON encoders replace malformed strings; both reject before work. |
| UTF-8 byte bound | Multibyte text exceeding the 256-byte fixture bound rejects even when its UTF-16 length fits. |
| Valid Unicode | A valid paired-surrogate fact remains business data and completes fresh reconstruction. |

Every dispatch requires actual exposure permission and a same-attempt settlement matching final accounting. Candidate receipts are compared to independent Host exchanges, including original repair backlink and acknowledgement classification. Parent assertions check child exits, finite timeouts, actual PIDs, effect files and exact counts; any failure exits nonzero. Ordinary results, progress, configuration, observations and stdout/stderr exclude synthetic sensitive canaries. Restricted capture may contain reasoning and corrections but must exclude credentials; capture is discarded rather than forwarded to B.

The `--keep-workspace` verifier option retains copied ignored `.local/scribe` observations for local inspection. Domain progress is distinct from ordinary diagnostics. One strict, control-free UTF-8 fact check protects both retained progress and newly accepted candidate facts. This fixture makes no production storage, distributed effect, campaign service, arbitrary process-kill, billing, actual Scribe migration, Native AOT or live-provider claim. It reads no real credential and performs no network or GitHub effect. No cross-version API or context compatibility is promised before formal release.
